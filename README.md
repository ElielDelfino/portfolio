# Portfólio

Portfólio pessoal desenvolvido com React, TypeScript e Vite.

## 🚀 Tecnologias

- React 18
- TypeScript
- Vite
- CSS3

## 📦 Instalação

```bash
npm install
```

## 🛠️ Desenvolvimento

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## 🏗️ Build

Para criar a build de produção:

```bash
npm run build
```

Os arquivos serão gerados na pasta `dist`

## 👀 Preview

Para visualizar a build de produção localmente:

```bash
npm run preview
```

## 📝 Personalização

### Atualizar Informações Pessoais

1. **Sobre Mim** - Edite `src/components/About.tsx`
2. **Projetos** - Edite o array `projects` em `src/components/Projects.tsx`
3. **Habilidades** - Edite o array `skillCategories` em `src/components/Skills.tsx`
4. **Contato** - Edite os links em `src/components/Contact.tsx`

### Personalizar Cores

Edite as variáveis CSS em `src/styles/global.css`:

```css
:root {
  --primary-color: #6366f1;
  --secondary-color: #8b5cf6;
  /* ... outras variáveis */
}
```

## 📄 Deploy

O projeto está pronto para deploy em plataformas como:

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

Basta fazer o build e fazer upload da pasta `dist` ou conectar seu repositório Git.
